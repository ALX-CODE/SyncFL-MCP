# SyncFL branding

[`syncfl-logo.png`](syncfl-logo.png) is the project logo supplied by the SyncFL maintainers on October 12, 2026. The original 2172 × 724 RGBA PNG is included unchanged, including its transparency and orange waveform.

Its SHA-256 is pinned in `public-release.json` so an altered asset requires a new review before export. The logo is project branding; it does not imply endorsement by Image-Line or plugin vendors.

## Social preview

[`syncfl-social-preview.jpg`](syncfl-social-preview.jpg) is the GitHub link-preview
banner: 1774 × 887 pixels (2:1), approximately 209 KiB. It was generated with
OpenAI's image-generation tool using the supplied logo, then encoded as JPEG at
quality 95 without resizing or changing its layout. The generated PNG remains a
local working asset; the unchanged original logo is the authoritative brand file.
The JPEG retains only non-personal encoding metadata, with no comments or
embedded personal paths. Its reviewed hash is
pinned in `public-release.json`.

The image records the inventory at creation time: 143 tools, 50 plugin profiles
and 4,872 named controls. These are inventory counts, not a claim that all
parameters are calibrated. Update the banner and its reviewed hash together
when the displayed counts change. GitHub stores the uploaded social image
separately, so a source change also requires a new upload in repository settings.
